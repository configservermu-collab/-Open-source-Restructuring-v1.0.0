====================================
  VIP IMAGES FOLDER
====================================

Place your VIP images in this folder.

RECOMMENDED IMAGE SPECIFICATIONS:
- Format: PNG with transparent background
- Size: 200x200 pixels (minimum) to 400x400 pixels (recommended)
- File names: vip1.png, vip2.png, vip3.png, vip4.png (or as configured in AdminCP)

DEFAULT FILE NAMES:
- vip1.png - VIP Type 1 (Bronze)
- vip2.png - VIP Type 2 (Silver)
- vip3.png - VIP Type 3 (Gold)
- vip4.png - VIP Type 4 (Platinum)

You can configure custom image names in:
AdminCP > VIP > Settings > VIP Image field

DESIGN TIPS:
- Use circular/medallion designs for best results
- High contrast colors work best
- Avoid too much detail - simple icons are more effective
- Transparent backgrounds recommended

EXAMPLE DESIGN IDEAS:
- Medallions with stars
- Crown icons
- Shield emblems
- Crystal/gem icons
- Tier badges

If an image is not found, a default star icon will be displayed.

FOLDER LOCATION:
This folder is at: img/vip/ (root of plugin upload)
